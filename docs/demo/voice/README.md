# 목소리 샘플 넣는 곳

## 무엇을 녹음하나

`docs/demo/narration.md`의 **[REF] 0:00–0:12 타이틀** 블록 두 문장.
그게 음성 복제의 레퍼런스이자 영상 도입부 내레이션으로 그대로 쓰입니다.

여유가 되면 대본 전체를 읽어주세요 — 복제 없이 진짜 목소리를 쓰는 게 항상 낫습니다.
복제는 나중에 대본을 고칠 때 재녹음을 피하려는 안전망입니다.

## 어떻게

- 조용한 방, 에어컨·선풍기 끄기
- 입에서 20~30 cm, 정면 살짝 비껴서 (파열음 방지)
- 한 번에 쭉. 틀리면 그 문장만 다시 읽고 이어가면 됩니다
- 맥 기본 녹음기(음성 메모)나 QuickTime > 새로운 오디오 녹음이면 충분합니다

## 어디에

이 폴더에 넣어주세요. 이름은 아무거나:

    docs/demo/voice/junsu-ref.m4a      # 또는 .wav .mp3 .aiff

여러 테이크가 있으면 다 넣어주세요. 제일 깨끗한 걸 고르겠습니다.

## 넣고 나서

한 마디만 해주시면 됩니다. 나머지는 제가 합니다 —
16 kHz 모노로 정규화, mlx-audio로 복제, 비트별 타이밍에 맞춰 합성, ffmpeg으로 영상에 합성.

# 한국어 설명 영상용 레퍼런스 (`ko-ref`)

설명 영상(`docs/demo/explainer/`)은 심사위원용 영상과 **다른 목소리**를 씁니다.
첫 판은 macOS 기본 음성으로 만들었는데 22 kHz 컴팩트 음성이라 듣기 괴롭습니다.

## 무엇을 녹음하나

`ko-ref.txt` 한 문단. 약 30초입니다. **8분 전체를 읽을 필요 없습니다** —
이 30초가 음성 복제의 레퍼런스가 되고, 나머지 8분은 그 목소리로 합성됩니다.

영어 녹음(`take2.m4a`)으로도 한국어 합성이 되기는 하지만, 영어를 말하는 입 모양이
한국어에 딸려 들어옵니다. 한국어 레퍼런스가 있으면 그게 사라집니다.

## 어떻게

- 조용한 방, 에어컨·선풍기 끄기
- 입에서 20~30 cm, 정면 살짝 비껴서
- **설명하는 톤으로**. 발표가 아니라 옆사람에게 알려주는 속도로
- 틀리면 그 문장만 다시 읽고 이어가면 됩니다

## 어디에

이 폴더에 `ko-ref.m4a`(확장자는 아무거나)로 넣고:

    python3 scripts/tts_ko.py --engine fish \
      --ref docs/demo/voice/ko-ref.m4a \
      --ref-text "$(cat docs/demo/voice/ko-ref.txt)"
    scripts/record_explainer.sh     # 컷 길이가 목소리에 맞춰 다시 잡힙니다
    scripts/mix_explainer.sh
