# Ontario MTO Commercial Vehicle Survey: Value of Goods 2016 (road links)

Source: Ontario Data Catalogue, "Commercial Vehicle Survey Data - Commercial Vehicle Flows Assigned to Road Network"
(https://data.ontario.ca/dataset/commercial-vehicle-survey-data-commercial-vehicle-flows-assigned-to-road-network),
served via the MTO iCorridor ArcGIS Hub item 0272164756d5404ebee0967fb9517ab2_0.
Downloaded 2026-09-01 as CSV (no registration). License: Open Government Licence - Ontario.

Columns: FID, RDNAME, RDNAME2, HWY_NUM, AADTT16 (annual average daily truck traffic, 2016), VOG_WGT, VOG16 (value of goods 2016), SHAPE_Length.
One row per provincial road link. Useful as a map layer or as a prior for truck density on Ontario highways, not for orders or trips.
